# 📱 Android Banking Application

A final project for the Advanced Programming course.

This project is an Android mobile banking application developed using Java.  
The application allows users to manage basic banking operations through a simple and user-friendly interface.

## ✨ Features
- User registration and login
- Credit card balance charging
- Money transfer between accounts
- Fund creation and management
- Loan request submission
- Add and remove contacts
- Ticket/request registration system
- Automatic response messages for user requests

## 🛠 Technologies
- Java
- Android Studio
- Object-Oriented Programming (OOP)

## 🎯 Purpose
The goal of this project was to practice Android development concepts, object-oriented design, and implementing a real-world banking application workflow.
